## 综合质量分数

### 计算公式
```
综合质量分数 = ∑(各指标得分 × 权重)
各指标得分 = (当前值 / 目标值) × 100 (最大100分)
```

## 附录

### 质量指标计算方法
1. **单元测试覆盖率** = (已覆盖代码行数 / 总代码行数) × 100%
2. **代码复杂度** = 平均圈复杂度（McCabe）
3. **安全漏洞数** = 高危漏洞 + 0.5×中危漏洞 + 0.2×低危漏洞
4. **API 响应时间** = 95百分位响应时间
5. **系统可用性** = (正常运行时间 / 总时间) × 100%

### 工具推荐
- 代码质量：SonarQube, JaCoCo, Checkstyle, PMD
- 安全性：OWASP Dependency Check, SonarQube Security
- 性能：JMeter, Gatling, Prometheus, Grafana
- 监控：Spring Boot Actuator, ELK Stack, New Relic
