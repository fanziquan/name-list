# Name-List 产品规范

## 概述
本文档是 Name-List 项目的产品规范索引，包含所有功能模块的详细需求说明。

## 产品愿景
打造一个专业、可靠、易用的人物信息管理系统，为历史研究、教育宣传等场景提供数据支持。

## 目标用户

### 主要用户
1. **系统管理员**
   - 负责系统配置和维护
   - 用户权限管理
   - 数据备份和恢复

2. **内容编辑员**
   - 人物信息录入和维护
   - 图片上传和管理
   - 内容审核和发布

3. **数据审核员**
   - 信息准确性验证
   - 内容合规性检查
   - 质量评估

### 次要用户
1. **公众用户**
   - 浏览人物信息
   - 搜索和筛选功能
   - 信息导出

## 核心业务流程

### 1. 人物信息录入流程
```
1. 登录后台 → 2. 选择人物类型 → 3. 填写基本信息 → 4. 上传图片 → 5. 填写详细描述 → 6. 保存提交
```

### 2. 内容审核流程
```
1. 编辑提交 → 2. 审核员接收 → 3. 信息验证 → 4. 合规检查 → 5. 批准/驳回 → 6. 状态更新
```

### 3. 图片管理流程
```
1. 选择图片 → 2. 格式验证 → 3. 压缩优化 → 4. OSS 上传 → 5. URL 存储 → 6. 缩略图生成
```

## 数据模型

### 人物数据模型
```yaml
人物基础信息:
  - ID: 唯一标识 (分类代码+序列号)
  - 姓名: 必填，长度限制
  - 生卒年份: 整数格式
  - 国籍: 从字典选择
  - 分类: MAR/SCI/GEN/PAT (正面) 或 WAR/COR/CRU/CRI (反面)
  - 简介: 200字内摘要
  - 详细描述: 完整事迹
  - 图片URL: OSS存储地址
  - 状态: 1-显示, 0-隐藏
  - 时间戳: 创建/更新时间
```

### 扩展信息模型
```yaml
扩展信息:
  - 相关人物: 关联其他人物ID
  - 历史事件: 参与的重要事件
  - 文化影响: 对后世的影响
  - 标签: 关键词标签
```

## 用户界面规范

### 1. 后台管理界面
- **布局**: 左侧导航 + 右侧内容区
- **风格**: 简洁专业，蓝白配色
- **响应式**: 支持桌面和移动端
- **交互**: 明确的操作反馈

### 2. 公共访问界面
- **布局**: 顶部导航 + 内容区 + 底部信息
- **风格**: 庄重典雅，符合主题
- **搜索**: 关键词搜索 + 高级筛选
- **详情**: 图文并茂，结构清晰

### 3. 表单设计规范
- 必填项明确标记
- 输入验证实时反馈
- 错误信息友好提示
- 操作按钮状态明确

## 性能要求

### 1. 响应时间
- 页面加载: < 3秒

### 2. 并发能力
- 支持 100+ 并发用户
